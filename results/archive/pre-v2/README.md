# Pre-Version-2 result archive

These artifacts are retained for provenance but are not canonical outputs.

- `prefix_suffix_analysis.json`: manually maintained, precomputed headline
  table superseded by a generated artifact and awaiting the Phase 2 estimator.
- `extended_analysis_results.json`: mixed retained, exploratory, invalid, and
  retired analyses in one schema.
- `constructed_control_results.json`: first-pass constructed control that does
  not represent the later adversarial generator.
- `per_scribe_results.json`: method-mismatched per-hand analysis pending rerun
  through the shared estimator.

No current test or document may use these files as scientific authority.

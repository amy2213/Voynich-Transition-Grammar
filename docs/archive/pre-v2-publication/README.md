# Pre-Version-2 publication archive

This directory preserves public-facing artifacts superseded during the July
2026 manuscript-alignment sprint. The files are retained to make corrections
and retractions auditable.

These documents and figures use pre-Version-2 methods and include claims that
were later retired, including flattened or unmatched prefix/suffix estimates,
canonical AIIN invariance, broad natural-language uniqueness, and outdated
test or pipeline descriptions. They must not be cited as current results.

`RELEASE_NOTES_v1.md` is the former root release-note file preserved with its
original Version 1 claims and obsolete paths.

Current authority is `docs/main.tex`, `docs/paper.pdf`, `docs/v2/`, and fresh
generated outputs named in `results/run_manifest.json`.
